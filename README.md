# Krypt Final Timed Challenge

A fast-paced Engineers' Day quiz challenge for B.Tech students.

## Features

- 12 randomly selected questions per attempt
- 90-second countdown timer
- Instant answer validation
- One-mistake-fails challenge format
- Progress tracking and timer urgency states
- Animated circuit-style background
- Success confetti and retry flow
- Responsive layout for desktop and mobile

## Run Locally

No build tools or dependencies are required.

1. Open `index.html` directly in a browser, or serve the folder with a local web server.
2. Select **Start Challenge**.
3. Answer all 12 questions before the timer reaches zero.

For a local server with Python installed:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Project Structure

- `index.html` - Page structure and quiz screens
- `styles.css` - Layout, visual styles, animations, and responsive rules
- `script.js` - Question bank, game state, timer, scoring, and interactions
